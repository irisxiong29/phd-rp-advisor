# Literature Quality and DOI Verification

Use this module whenever proposing, citing, or reviewing academic literature.

## Principle

Reference accuracy is a hard requirement.
A plausible-looking citation is not acceptable evidence.

## Source hierarchy

Prefer, in roughly this order:

1. Peer-reviewed articles in established field journals
2. University-press or major academic-press books
3. Highly relevant recent articles in reputable specialist journals
4. Authoritative edited volumes / handbook chapters
5. Reports only when they supply necessary industry/policy data

Treat:
- preprints
- dissertations
- conference papers
- trade publications
- blog posts
as supplementary unless the field requires them.

## Core benchmark literature

A benchmark reference should do at least one of these:
- closely study the same phenomenon
- offer the theoretical concept the project actually uses
- establish the relevant empirical field
- demonstrate a method/design the student can realistically adapt

Do not label a famous but distant text as a "core benchmark" simply because it is prestigious.

## Verification procedure

When web access is available, verify important references using at least one authoritative source:
- DOI resolver / Crossref metadata
- publisher/journal page
- official book publisher page

For especially important or surprising references, cross-check with a second source.

Verify:
- author names
- year
- title
- journal/book title
- volume/issue
- page range or article number
- DOI

## DOI rules

- Present DOI links as `https://doi.org/<DOI>`.
- Do not invent a DOI from a title.
- Do not assume every book/chapter has a DOI.
- If no DOI can be verified, write `DOI not verified/available` rather than fabricating one.
- A URL that merely contains a DOI-looking string is not sufficient if metadata does not match.

## Literature mix

For a typical RP outline:
- include seminal work only when conceptually necessary
- include recent work to show the current conversation
- include closely aligned empirical studies
- include China-specific or region-specific studies when the project depends on that context
- do not let "recent" automatically displace a foundational text

## Research-gap discipline

Avoid generic gap claims such as:
- "few studies have examined..."
- "there is limited research..."
unless the search genuinely supports them.

Prefer gaps framed as:
- conceptual limitation
- change in empirical conditions
- missing relation between literatures
- overlooked mechanism/process
- scale or level mismatch
- methodological blind spot
- context that changes how a concept operates

When evidence only supports a tentative gap, phrase it cautiously.

## During draft review

Flag:
- citations that do not support the sentence
- outdated claims presented as current
- secondary citations used in place of accessible originals
- inconsistent author/year
- suspicious or unverifiable references
- DOI mismatches
- literature that appears decorative
