# Suggested Student Workspace

This folder is only a template. Copy it for each student.

Recommended structure:

- `00_input/`
  - CV
  - supervisor-choice spreadsheet
  - writing samples
- `01_icebreaker/`
  - icebreaker slide outline / PPT
  - first class transcript
- `02_topic_brainstorm/`
  - topic comparison
  - topic-selection transcript
- `03_outline/`
  - current outline
  - literature notes
- `04_annotated_outline/`
- `05_full_draft_review/`
  - student full RP v1
  - review comments
- `06_final_proofread/`
  - student RP v2
  - final edited version

Keep one student's materials in one workspace to prevent cross-case contamination.
